# HUBmath 개인 홈페이지

hubmath.com 디자인을 기반으로 만든 정적 개인 홈페이지입니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소 생성: `hanshin877.github.io` (또는 원하는 이름)
2. 이 폴더의 파일들을 저장소에 업로드
3. Settings → Pages → Source: `main` 브랜치 선택
4. `https://hanshin877.github.io` 로 접속

## 파일 구조

```
index.html      ← 메인 페이지
css/style.css   ← 스타일 (hubmath.com Smart 레이아웃 기반)
js/main.js      ← 인터랙션 스크립트
.nojekyll       ← GitHub Pages Jekyll 비활성화
```

## 커스터마이징

- `index.html`에서 이름, 연락처, 자료 목록 수정
- `css/style.css`의 `--accent: #f26859` 값으로 포인트 컬러 변경
